Movie Code

Ein ausgewählter Benutzer kann die Mediathek normal durchsuchen. Sobald er einen Film startet, fragt das Plugin den 6-stelligen Einmalcode ab und gibt danach genau diesen Film frei. Nach dem Filmende verfällt die Freigabe.

Einstellungen

Optional. Leer lassen, dann wird die Adresse aus der aktuellen Server-URL gebildet.
0 = der Code bleibt gültig, bis der Film zu Ende geschaut oder die Freigabe aufgehoben wird.
0 = kein Limit. Empfohlen: 5.
Standardmäßig bleibt die Freigabe beim Stoppen erhalten, damit der Film fortgesetzt werden kann.
Wenn deaktiviert, bleibt der Benutzer gesperrt, bis du die Freigabe unten aufhebst.
Gilt für Browser, Jellyfin Media Player und PWA. Native Apps zeigen kein Popup; dort kann der Code weiterhin über die Freigabeseite eingegeben werden.
Wird dem Benutzer angezeigt, wenn er etwas anderes starten möchte.

Neue Freigabe

Der Benutzer wählt den Film selbst aus. Der Code wird beim ersten Start an diesen Film gebunden.

Freigaben
