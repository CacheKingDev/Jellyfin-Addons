Movie Code

Ein ausgewählter Benutzer kann die Mediathek normal durchsuchen. Sobald er einen Film startet, fragt das Plugin einen 6-stelligen Einmalcode ab und gibt danach genau diesen Film frei. Jeder Code gilt nur einmal. Nach dem Filmende kann der Benutzer mit einem weiteren Code aus dem Paket den nächsten Film freischalten.

Einstellungen

Optional. Leer lassen, dann wird die Adresse aus der aktuellen Server-URL gebildet.
0 = die Codes bleiben gültig, bis sie verwendet oder die Freigabe aufgehoben wird.
0 = kein Limit. Empfohlen: 5.
Standardmäßig bleibt die Freigabe beim Stoppen erhalten, damit der Film fortgesetzt werden kann.
Wenn deaktiviert, bleiben die übrigen Einmalcodes gültig und der Benutzer kann mit dem nächsten Code einen weiteren Film freischalten. Wenn aktiviert, werden beim Filmende alle übrigen Codes ungültig.
Gilt für Browser, Jellyfin Media Player und PWA. Native Apps zeigen kein Popup; dort kann der Code weiterhin über die Freigabeseite eingegeben werden.
Wird dem Benutzer angezeigt, wenn er etwas anderes starten möchte.

Einmalcodes pro Benutzer

Die Code-Pakete werden direkt in der Kindersicherung des jeweiligen Benutzers erzeugt und verwaltet. Öffne dazu Benutzer, wähle den Benutzer aus und öffne den Reiter Kindersicherung. Dort findest du den Bereich „Movie Code – Einmalcodes“.
