▶ Jellyfin · Film-Freigabe

Einmalcode eingeben

Gib den 6-stelligen Code ein und starte danach den gewünschten Film in Jellyfin. Der erste gestartete Film wird für dich freigegeben.

Der Code kann nur einmal eingelöst werden und gilt für den ersten Film, den du danach startest.

Im Browser und in Jellyfin Media Player erscheint das Code-Fenster direkt beim Start des Films. Diese Seite ist der Fallback für native Apps.

Nach dem Filmende verfällt die Freigabe. Danach wendest du dich an den Administrator.
